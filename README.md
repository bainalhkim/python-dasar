## 🚀 Getting Started

### Prerequisites

- [Python 3.8+](https://www.python.org/downloads/)
- Git
- A code editor (VS Code, PyCharm, etc.)

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/[username]/python-dasar.git

# 2. Enter the project folder
cd python-dasar

# 3. (Optional) Create a virtual environment
python -m venv venv
source venv/bin/activate        # Linux / macOS
venv\Scripts\activate           # Windows

# 4. Install dependencies (standard library only)
pip install -r requirements.txt
```

### Run

```bash
python python-dasar.py
```

> **Note:** Chapters 18 and 19 require supporting files (`kalkulator.py` and the `perhitungan/` package) in the same directory. See [Project Structure](#-project-structure).

## 💡 Code Snippets

**Class & Inheritance**

```python
class Hewan:
    def __init__(self, nama):
        self.nama = nama

    def suara(self):
        print("This animal makes a sound")

class Kucing(Hewan):
    def suara(self):
        print(self.nama, "says: Meow")

Kucing("Mimi").suara()
```

**Exception Handling**

```python
try:
    hasil = 10 / 0
except ZeroDivisionError:
    print("Error: cannot divide by zero")
```

## 🎯 Learning Objectives

After finishing all chapters, you should be able to:

- Write simple, well-structured Python programs.
- Use data types, operators, and control flow correctly.
- Create functions and classes, and apply the four OOP pillars (Encapsulation, Inheritance, Polymorphism, Abstraction).
- Handle errors and read/write files.
- Organize code into modules and packages.
